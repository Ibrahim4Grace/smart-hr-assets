Smart-HR Static Assets

This repository contains static assets for the Smart-HR application

Available Asset Folders

  • 📁 Background Images (bg/) - Logo and background images
  • 📁 Stylesheets (css/) - CSS files and styles
  • 📁 Fonts (fonts/) - Web fonts and icon fonts
  • 📁 Images (images/) - Application images and icons
  • 📁 JavaScript (js/) - JavaScript files and scripts
  • 📁 Plugins (plugins/) - Third-party plugins and libraries
  • 📁 API Scripts (apis-script/) - API integration scripts

Usage

These assets are served via Cloudflare Pages and can be accessed using the following base URL:

https://your-cloudflare-domain.pages.dev/

Example: https://your-cloudflare-domain.pages.dev/css/style.css

Deployment

This repository is configured for automatic deployment to Cloudflare Pages. Any changes pushed to the main branch will automatically trigger a new deployment.
